1. Project Overview
1.1 Abstract
RENATHA is a web-based Pharmacy Inventory & Expiry Alert System designed for small and
medium pharmacies in East Africa. It solves three critical operational problems: sale of expired
drugs due to absent tracking, poor stock visibility leading to shortages, and lack of affordable
digital tooling in low-connectivity environments.
The system combines a Laravel REST API with a React.js single-page application, MySQL for
storage, and Africa's Talking APIs for SMS/USSD — ensuring accessibility even without a
stable internet connection.

1.2 Objectives
General Objective
Develop a digital pharmacy inventory system that improves drug safety and inventory efficiency
in low-resource environments.

Specific Objectives

Implement automated expiry tracking with configurable alert thresholds (30 / 14 / 7 days)
Provide real-time inventory monitoring per drug and per batch
Enable low-stock notifications when quantity falls below reorder level
Integrate SMS and USSD for offline / low-connectivity access
Develop a role-based user interface for Admin, Pharmacist, and Cashier
Maintain accurate sales records with automatic stock deduction

2. Frontend Setup (React + Vite)

💡

Target environment: Windows 10/11 — developer familiar with web dev but new to React.

2.1 Prerequisites — Install Node.js
1. Go to nodejs.org and download the LTS version (v20.x or v22.x)
2. Run the installer, ensure 'Add to PATH' is checked
3. Open a new PowerShell window and verify:
node -v
npm -v

Expected output: version numbers such as v20.x.x and 10.x.x

2.2 Install VS Code & Extensions
4. Download from code.visualstudio.com and install with defaults
5. Inside VS Code, install these extensions (Ctrl+Shift+X):
1. ES7+ React/Redux Snippets
2. Prettier – Code Formatter
3. Tailwind CSS IntelliSense
4. GitLens (optional)

Open PowerShell, navigate to your projects folder, and run:

6.2 SMS Alert Logic
Create a Laravel scheduled command (app/Console/Commands/CheckExpiryAlerts.php) that
runs daily:
• Queries batches where expiry_date is 30, 14, or 7 days away
• Queries batches where quantity <= drug.reorder_level
• Sends an SMS to all users with role admin or pharmacist
• Creates an entry in the alerts table
Register the command in app/Console/Kernel.php:
protected function schedule(Schedule $schedule) {
$schedule->command('alerts:check-expiry')->daily();
}
